# 室内扫描点云 → 网格制作平台

把带观测方向的室内扫描点集，经过**噪点候选筛查 → 自适应法线估计 → 受支持的表面重建 → 输出质检**，
在网页视窗中同时呈现原始点与生成的网格，并可导出标准网格文件。

纯 Node.js ESM 实现，**几何内核零第三方依赖**（自写 KD-tree、Jacobi 特征分解、BPA、平面区域生长）；
前端使用本地化的 Three.js（无构建步骤、可离线运行）。

---

## 一、怎样启动界面

```bash
# 1. 生成五个合成验证场景（写入 ./data，已被 .gitignore 忽略）
npm run gen-data

# 2. 下载并本地化 Three.js r160 到 web/static/vendor（需要一次性联网）
npm run vendor

# 3. 启动零依赖 HTTP 服务
npm start
# 控制台输出：室内点云重建平台已启动: http://localhost:8080
```

浏览器打开 <http://localhost:8080> 即可。端口可用环境变量覆盖：`PORT=9000 npm start`。

> 若无法联网，把 `three.module.js` 与 `addons/controls/OrbitControls.js` 手动放到
> `web/static/vendor/` 对应路径即可，服务本身与重建内核不需要网络。

命令行自检（不启动服务，覆盖全部验证场景与诚实性红线）：

```bash
npm run selftest
```

## 二、界面操作流程（模型操作视窗）

1. **载入点云（可设置尺度）**：左侧选择内置场景 `s1`–`s5`，或上传 `.json/.xyz/.txt/.pts/.ply`。
   顶栏“显示尺度”只改变可视化缩放，**不会改写原始数据**。
2. **设置参数**：参数控件由重建内核的 `PARAM_SCHEMA` 自动生成，前端不允许提交内核不认识的参数。
3. **运行重建**：结果区呈现重建表面、橙色**边界边**、红色**法线歧义点**、橙色**未支撑点**；
   勾选“按观测距离着色”可按点到传感器的距离对原始点着色。
4. **失败反馈回到点云重建**：失败时视窗下方弹出面板，给出失败阶段、定位信息与修复建议，
   引导回左侧调参或在噪点面板恢复边界点后重跑——而不是静默产生错误网格。
5. **噪点候选（可恢复）**：候选只标记不删除；勾选后“剔除所选”产生修订版，
   “恢复候选”可从冻结的原始点云把误删点取回。
6. **导出网格**：右侧导出 PLY（ASCII/二进制）、OBJ、JSON（含冻结参数与质检报告）。

## 三、内核算法（真实算法，不是只显示点云）

| 阶段 | 实现 |
| --- | --- |
| 自适应局部尺度 | 逐点中位 kNN 距离，2–98 百分位稳健截断；**每个点尺度不同，绝不全局统一**（`src/core/stats.js`） |
| 噪点筛查 | SOR 统计离群 + 孤立半径判定，**只标记不删除**，保留 z-score/邻居数等量化指标（`noise.js`） |
| 法线估计 | 邻域质心 + 距离加权 PCA + 3×3 对称 Jacobi 特征分解；最小特征值特征向量为法线（`normals.js`、`eig.js`） |
| 法线定向 | 参考观测来源，约定 `n·(viewPoint − p) > 0`；无观测点经 MST 传播并**显式标记朝向歧义**（flag 4/8） |
| BPA 重建 | 球旋转：种子三角、有向前沿边、空球测试、多半径递进、切平面 Delaunay 回退、边界愈合、流形/支撑守卫（`reconstruct/bpa.js`） |
| 平面重建 | 区域生长 + PCA 平面拟合 + 共面合并 + 切平面占据栅格三角化，**空栅格一律留白**（`reconstruct/planar.js`） |
| 输出质检 | 退化面、边邻接连通区域、点到三角面距离统计（`meshqc.js`） |

### 受支撑与防搭桥

BPA 与平面后端都要求面片由真实观测点支撑：内心独立支撑、边中点支撑、切平面覆盖率、
最大边长限制、流形边（每条边至多两个面）、同侧重叠拒绝等。
**不会**为了让网格“看起来完整”而跨越无数据区域。

## 四、诚实性保证（核心约束）

- **不自动封洞**：缺墙、玻璃无回波、遮挡空洞作为真实开放区域保留，以边界边和空栅格显式呈现。
  - `s4_missing_wall`：两个后端在 `+X` 开口处面片数均为 **0**。
  - `s5_glass_hole`：平面后端报告 **161 个保留空栅格**，玻璃矩形内面片数为 **0**。
- **距离小 ≠ 拓扑真实**：质检报告固定附带声明——点到网格距离小只表示几何贴合，
  空洞、缺墙与朝向仍须结合边界边与法线标记人工确认。
- **原点不可覆盖**：`PointCloud` 载入即冻结并计算 sha256 哈希；任何修订都生成带血缘的新版本，原数组只读保留。
- **参数与输入冻结**：每次运行保存 `frozen.paramsSnapshot` 与输入哈希，结果可追溯、可复现。
- **误删可恢复**：噪点候选可随时从原始冻结点云恢复。
- **无法唯一确定的朝向必须标记**：无观测方向、邻居定向冲突的点在视窗中红色高亮并带 flag 标签。

### 已知几何局限（如实披露，不伪装）

BPA 在玻璃矩形**洞缘**可能形成极少量受支撑窄三角（`s5` 约 7 个），其三个顶点都是洞缘外的真实观测点。
当三侧都有数据时，局部上无法把它与真实凹角区分，因此选择保留并在质检中可计数，
而不是用启发式静默删除可能真实的结构。平面后端不存在该问题（洞矩形内为 0 面片）。

## 五、验证场景与自测结论

`npm run selftest` 运行 40 项断言，覆盖：

| 场景 | 验证点 |
| --- | --- |
| `s1_planar_room` 已知平面房间 | 两端口大量面片、零退化、毫米级点面距离、含拓扑免责声明 |
| `s2_density_jump` 密度骤变 | 逐点尺度离散（自适应证据）、不产生超长搭桥、距离可控 |
| `s3_isolated_noise` 孤立噪点 | 8 个远距离群点全命中、只标记不删除、修订后可恢复、原点哈希不变 |
| `s4_missing_wall` 缺一面墙 | **开口零面片**、边界边存在（红线） |
| `s5_glass_hole` 玻璃缺测 | 平面后端空栅格>0 且矩形内零面片；BPA 洞缘面受限并可披露 |
| 退化共线输入 | 抛出带失败阶段与修复提示的 `PipelineError` |
| 参数对照 | 同一输入 `gridFactor=0.75 vs 2.0` 的面片数/组件/距离量化对比 |

## 六、目录结构

```
src/
  core/           零依赖几何内核（KD-tree、特征分解、点云、IO、法线、噪点、质检、流水线、schema）
    reconstruct/  bpa.js（球旋转）、planar.js（平面区域生长）
  server/         server.js 零依赖 node:http 服务（载入/修订/运行/导出/schema）
web/
  index.html      视窗与三栏工作台
  app.js          Three.js 渲染 + schema 驱动控件 + 失败/修订联动
  styles.css
  static/vendor/  本地化 Three.js r160 与 OrbitControls
test/
  make_data.js    五个合成场景生成器
  selftest.js     命令行自测
scripts/
  fetch_vendor.sh 供应商下载与导入路径改写
data/             生成的场景数据（git 忽略）
```

## 七、HTTP API 摘要

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/schema` | 内核参数 schema 与默认值（驱动前端控件） |
| GET | `/api/scenarios` | 内置场景列表 |
| POST | `/api/load-scenario` | 按名载入场景 |
| POST | `/api/upload` | 上传点云（multipart 或 raw body） |
| GET | `/api/cloud` | 当前点云摘要 |
| POST | `/api/revise` | `mode=remove/restore` 产生修订版（原点不动） |
| POST | `/api/run` | 运行流水线；失败返回 422 + `pipelineError`（阶段/定位/提示） |
| GET | `/api/run/latest` | 最近一次运行结果 |
| GET | `/api/export?format=ply|plybin|obj|json` | 导出网格 |
